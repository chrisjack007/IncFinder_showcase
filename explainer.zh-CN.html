结论

IncFinder 用 NTv3 650M 特征和两阶段冻结 RF，逐序列预测 21 类 Inc 标签。新序列编码仍属研究预览。12

  1. 编码器对原序列和反向互补序列生成 1536 维 FP32 特征。3
  2. Stage 1 按 P1 >= 0.5 门控；一个多输出 Stage 2 RF 处理通过子集。4
  3. V2 保留原始概率、内部状态、模型身份和运行信息。56

适用于V2 / 0.4.0逐序列研究预览

  1. 序列校验 ↗

    读取 FASTA、FASTQ 或 gzip；检查 ID、碱基与允许长度。

  2. NTv3 编码 ↗

    用 N 补齐到 128 的倍数。按原始位置池化，再对正反两条链取均值。

  3. 特征文件 ↗

    使用 features.npy 和绑定元数据；也可校验完全匹配的 --features-dir。

  4. Stage 1：Inc 检测 ↗

    第一层冻结 RF 含 500 棵树，处理全部记录。

  5. Stage 1 门控 ↗

    仅 P1 >= 0.5 进入 Stage 2；拒绝行的 Stage 2 概率保留 NA。

  6. Stage 2：Inc 分型 ↗

    一个含 500 棵树的冻结 RF，对通过记录输出 21 个正类概率。

  7. 预测后处理 ↗

    按 >= 与固定阈值比较，生成最终调用和内外部状态。

  8. 运行追溯信息 ↗

    复核输入，写入摘要与版本，最后发布完整结果目录。

统一 API 控制本地 Python 工作进程。箭头表示数据或依赖，不表示实测耗时。预计算特征跳过编码，仍须校验全部冻结模型。78

如何准备和运行？

使用 Windows Git Bash 或 Linux Bash。支持 Python 3.11/3.12，默认环境采用 3.12。安装与完整软件文档需要仓库访问权。先安装软件，再准备模型文件。9

按固定版本的模型准备说明准备 models/rf/ 和 models/ntv3/。V2 复用 V1 的 RF 附件。NTv3 需用自己的账户向官方提供方取得访问权，并保留许可证。准备完成后，推理使用本地文件。10

doctor 检查元数据与文件大小，不加载模型。check 校验完整 SHA-256；check --quick 只校验大小。每次运行需选择尚不存在的输出目录。默认参数为 batch-size=1、threads=4、jobs=1 和 threshold-mode=ct。117

API 返回运行摘要字典，操作失败时抛出 IncFinderError。新接口的用户路径按调用者当前目录解析。CPU Docker 包装器使用同一 CLI，推理时关闭网络，只读挂载输入与模型。详见完整参数。112

输出如何判读？

ct 使用训练 OOF 冻结的 21 个标签阈值；u05 对所有标签使用 0.5。两种模式均采用 >=，等于阈值时也通过。预测输入不参与阈值选择。1412

文件含义
layer1_decisions.csvStage 1 概率、0.5 阈值与原生门控
layer2_probabilities.csv21 类原始概率；拒绝行为 NA
inc_label_predictions.csv21 个最终二值调用、对外标志及 gate_pass、internal_status
inc_results.csv对外最终状态与分号分隔的标签
inc_predictions.xlsx对应四张表，并完成回读校验
probabilities.npz原始概率、gate、调用及内外部状态数组
prediction.json / run_summary.json阈值、标签顺序、计数、哈希、版本和科学状态

四张表均保留 Scientific_status。NPZ 中 Stage 1、Stage 2 概率分别为 (N,)、(N,21) 的 float32 数组。gate 为 bool，调用为 uint8，另有内外部状态。5

拒绝行在 NPZ 中为 NaN，在表格中为字面值 NA。准确标签顺序写入 prediction.json。5613

条件internal_status对外结果
P1 < 0.5UnclassifiedInc Unclassified
P1 >= 0.5，21 类调用全零Inc_no_callInc Unclassified
P1 >= 0.5，至少一个标签命中Inc_called分号分隔的 Inc 标签

V2 对外未分类表示最终 21 类调用全零。通过 gate_pass 区分门控拒绝与通过后无命中。无效或缺失预测会让运行失败，不能替换成有效的全零行。1 - P1 不能用作合并后未分类类别的连续评分。5

使用预测前需要检查什么？

科学状态仍有限制

新序列编码相对原冻结特征的等价状态仍为 NOT_ESTABLISHED。原始序列预测必须显式指定 --allow-encoder-drift，并保留 RESEARCH_PREVIEW。11 条选定参考记录用于工程回归，不能估计总体准确率。2

预测描述一条输入序列。未分类不能证明生物学不存在。软件不定位复制子、不估计群落丰度，也不能证明完整质粒存在。25
