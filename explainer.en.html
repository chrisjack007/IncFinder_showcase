How does IncFinder turn a sequence into Inc labels?

Long image

A

Answer

IncFinder predicts 21 plasmid incompatibility labels for each DNA sequence using NTv3 650M features and two frozen random forests. New-sequence encoding remains a research preview.12

  1. The encoder produces 1536 FP32 values from each sequence and its reverse complement.3
  2. Stage 1 gates records at P1 >= 0.5; one multioutput Stage 2 RF types the passing subset.4
  3. V2 preserves raw probabilities, native states, model identity and run metadata.56

  1. Sequence validation ↗

    Read FASTA, FASTQ or gzip; check IDs, bases and accepted length.

  2. NTv3 embedding ↗

    Pad with N to a multiple of 128. Pool original positions, then average both strands.

  3. Embedding artifacts ↗

    Use features.npy plus bound metadata, or verify an exact matching --features-dir.

  4. Stage 1: detection ↗

    Apply the first frozen 500-tree RF to all records.

  5. Stage 1 gate ↗

    Only P1 >= 0.5 enters Stage 2. Rejected Stage 2 rows remain NA.

  6. Stage 2: Inc typing ↗

    One frozen 500-tree RF returns 21 positive-class probabilities for passing records.

  7. Prediction decisions ↗

    Compare each probability with its frozen threshold using >=. Derive public and native states.

  8. Run provenance ↗

    Verify inputs again, write hashes and versions, then publish the completed directory.

The API controls local Python workers. Arrows show data and dependencies, not a measured timing trace. Precomputed features skip encoding; the run still verifies all frozen model assets.78

How do I prepare and run it?

Use Windows Git Bash or Linux Bash. Python 3.11/3.12 is supported; the default environment uses 3.12. Installation and full software documentation require repository access. Install the software before preparing model files.9

Prepare models/rf/ and models/ntv3/ using the pinned model instructions. V2 reuses the V1 RF assets. Obtain NTv3 from its official provider with your own approved access and retain its license. Prediction uses local files after preparation.10

doctor checks metadata and file sizes without loading models. check verifies complete SHA-256 values; check --quick checks sizes only. Choose a new output directory for every run. Defaults are batch-size=1, threads=4, jobs=1 and threshold-mode=ct.117

The API returns the run-summary dictionary and raises IncFinderError on operational failure. Modern user paths follow the caller's working directory. The CPU Docker wrapper uses the same CLI with read-only input/model mounts and networking disabled during prediction. See full usage.112

How should I read the results?

ct uses 21 label-specific training-OOF thresholds. u05 uses 0.5 for every label. Both modes keep >=, including equality; neither mode selects thresholds from the prediction input.1412

FileMeaning
layer1_decisions.csvStage 1 probability, 0.5 threshold and native gate
layer2_probabilities.csv21 original probabilities; rejected rows contain NA
inc_label_predictions.csv21 final binary calls, public flags, gate_pass and internal_status
inc_results.csvFinal public result and semicolon-separated labels
inc_predictions.xlsxThe four corresponding tables, with read-back checks
probabilities.npzRaw probabilities, gate, calls and public/native state arrays
prediction.json / run_summary.jsonThresholds, label order, counts, hashes, versions and scientific status

All four tables retain Scientific_status. NPZ contains Stage 1 (N,) and Stage 2 (N,21) float32 probabilities, a bool gate, uint8 calls and public/native states. Rejected Stage 2 probabilities are NaN in NPZ and literal NA in tables. prediction.json records the exact label order.5613

V2 defines public Unclassified as final 21-label zero. Use gate_pass to distinguish native rejection from a gate-passing no-call. Invalid or missing predictions fail the run; they are never replaced with a valid all-zero row. 1 - P1 is not a continuous score for the merged public class.5

What must I check before using a prediction?

Scientific status remains limited

New-sequence encoding remains NOT_ESTABLISHED against the original frozen features. Raw prediction requires --allow-encoder-drift and records RESEARCH_PREVIEW. The 11 selected reference records test engineering preservation, not population accuracy.2

A prediction describes one supplied sequence. An unclassified result does not establish biological absence. The software does not locate replicons, estimate community abundance or prove that a complete plasmid exists.25
