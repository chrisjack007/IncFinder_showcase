# IncFinder RF 0.5.0rc2.1

This release distributes the two frozen IncFinder 0.5.0rc2 RF models. The signed `rf-index.json` identifies the 23 downloadable files, their byte sizes and SHA-256 values, the two assembled models, and the compatible NTv3 revisions. The launcher verifies this index against the published release key. The CPU example uses the fixed 21-class rc2 reference.

本发行提供冻结 RF 的 23 个文件。使用软件启动器自动安装，或将已下载的分片目录交给便携版 `models init --parts-dir DIRECTORY`。NTv3 权重及基础实现由 Hugging Face 官方授权来源提供。[模型卡](https://github.com/chrisjack007/IncFinder_showcase/blob/v0.5.0rc2/docs/MODEL_CARD.zh-CN.md)
